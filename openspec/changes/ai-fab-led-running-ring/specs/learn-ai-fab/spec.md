# learn-ai-fab

## MODIFIED Requirements

### Requirement: The AI FAB ring is a running multi-colour LED border
The AI FAB's animated ring SHALL be a conic-gradient that fills the ENTIRE ring with colours
(no large transparent gap), rotating so the colours run continuously around the border — a
"running LED" look, not a single sweeping arc. Under reduced-motion the ring SHALL not animate.

#### Scenario: Colours run around the whole border
- **WHEN** the AI FAB renders with motion allowed
- **THEN** a multi-colour gradient fills the full ring and the colours travel around the border
